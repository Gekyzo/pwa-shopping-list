# Notes de version

Ce qui change pour vous dans chaque version de l’app. La version la plus récente vient en premier.

## Unreleased

- Connectez-vous pour retrouver vos listes sur tous vos appareils. Demandez l’accès avec votre e-mail ou avec Google ; Ciro approuve chaque compte. Une modification sur un appareil arrive sur les autres en quelques secondes, et hors ligne vos modifications sont enregistrées puis envoyées plus tard. Si vous avez déjà une liste, elle reste : l’avis `Connectez-vous pour synchroniser` l’envoie sur votre compte.
- `Réglages` › `Aide` › `Nouveautés` montre ce qui change dans chaque version. Après une mise à jour, la page s’ouvre une fois toute seule.
